# Meu portfólio

Portfólio pessoal de uma página, em português, com uma breve apresentação,
informações sobre aprendizado de Docker e interesses em desenvolvimento de
software. O conteúdo é apresentado com HTML semântico e CSS puro, em um layout
responsivo.

## Estrutura

- `index.html` — estrutura e conteúdo das seções da página.
- `styles.css` — estilos visuais, responsividade e estados de foco.
- `README.md` — descrição do projeto e de seus arquivos.
